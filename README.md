# 香港保单服务体验

给已经买过香港保单的内地客户用的服务评价页。只问办理和售后，不卖保险，也不收集证件号或完整保单号。

页面发布在这个仓库自己的 GitHub Pages 上。这是从真实情景抽出的练习，不会投入生产，没有做备案，也没有服务器。

## 本地打开

```bash
npm start
```

然后用浏览器访问 `http://127.0.0.1:43123`。

```bash
npm test
```

检查手机微信判断，以及 Cloudflare `loc=` 的读取。

## 打开条件

1. 只在手机微信里进入。电脑浏览器、手机自带浏览器、电脑上的微信都会看到「请用手机微信打开」。
2. 页面会请求 `https://www.cloudflare.com/cdn-cgi/trace`，读取其中的 `loc=`。结果是 `HK` 时显示「香港地区无法打开」。
3. 如果这次请求失败，或结果里没有 `loc=`，问卷不会出现，页面说明无法确认地区，并可以重试。
4. 答案只写在当前浏览器会话里（`sessionStorage`），不上传。成功页会写明这一点。

## 限度

浏览器标识可以伪造，所以「只在手机微信打开」挡不住有意改装的客户端。地理位置在浏览器里查询，访客可以不让这步发生，从而跳过香港判断。`github.io` 没有境内备案，在内地手机微信里可能打不开，或先出现安全提示。
